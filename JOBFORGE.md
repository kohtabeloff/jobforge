# JobForge 🔨

**Настраиваемый AI-помощник для поиска работы под разные цели.**

JobForge берёт зрелый движок [career-ops](https://github.com/santifer/career-ops)
(оценка вакансий A–F, подгонка резюме и сопроводительных писем, генерация PDF,
трекер) и добавляет к нему то, чего там не хватало для **разных людей с разными
целями**:

- 🎯 **Мастер настройки** — спрашивает твою цель и включает нужные источники.
- 🌍 **Несколько источников поиска** (источник = цель):
  - **ATS-watchlist** — конкретные компании (стартапы или крупные) — *из career-ops*
  - **JobSpy** — широкий захват: LinkedIn / Indeed / Glassdoor / Google
  - **hh.ru** — российский рынок (удалёнка)
  - *(в планах: Upwork/Kwork — фриланс, Telegram-каналы)*
- 🧹 **Humanizer** — убирает «робо-стиль» из писем и резюме.

Все источники складывают вакансии в один список `data/pipeline.md`, а движок
career-ops их оценивает и делает отклики.

## Быстрый старт

```bash
# 1. Установка одной командой (Node-зависимости + Python/JobSpy + конфиги)
bash setup.sh

# 2. Открой папку JobForge в Claude и напиши: «настрой JobForge»
```

Дальше JobForge ведёт по 5 шагам: **профиль → опрос про поиск → поиск+оценка →
выбор → подготовка материалов** (подаёшь сам).

## Поиск под цель

| Цель | Команда |
|------|---------|
| Широко по рынку (международно) | `./.venv/bin/python sources/jobspy_search.py "<запрос>" --remote` |
| Российский рынок | `node hh-search.mjs "<запрос>"` |
| Конкретные компании | `/career-ops scan` |
| Оценить найденное | `/career-ops pipeline` |

Подробности по источникам и мастеру — в `modes/_custom.md`.
