# /find — единый поиск вакансий JobForge

Запускается командой `/find` ИЛИ когда пользователь говорит «найди вакансии»,
«поиск работы», «поищи работу», «search jobs».

Принцип: **не спрашиваем про источники/площадки** (это внутренняя кухня) —
спрашиваем про саму работу, а нужные площадки подбираем сами. Ищем по
**ВСЕМ подходящим площадкам**, а «подходит/нет» решает оценка по резюме на
следующем шаге. Все находки идут в общий `data/pipeline.md`.

---

## Шаг 1. Настройки поиска (спрашиваем ОДИН раз, потом помним)

Сначала прочитай `config/profile.yml` → `search_prefs`.
- **Если есть** — используй как настройки по умолчанию. НЕ задавай 4 вопроса заново,
  только коротко подтверди: «Ищу: удалёнка, наём + фриланс, по резюме — так?»
  Если пользователь хочет поменять — поменяй и **сохрани новые значения в `search_prefs`**.
- **Если нет** (первый раз) — задай 4 вопроса ниже и **сохрани ответы в `search_prefs`**.

Вопросы (через AskUserQuestion):

1. **Откуда брать запросы:**
   - 📄 По резюме (возьму роли из профиля автоматически)
   - ✍️ Впишу свои ключевые слова
2. **Тип занятости:** Полная / Частичная / Фриланс (проекты)
3. **Формат:** Удалённо / На месте
4. **Локация** — задать ТОЛЬКО если «на месте»: «В каком городе/стране?»
   (если «удалённо» — НЕ спрашивай, география не важна; страновую пригодность
   роли проверит оценка по резюме).

## Шаг 2. Собрать запросы

- **По резюме:** возьми слова из `config/profile.yml` → `search_prefs.keywords`
  (их заполняет `/setup` из резюме). Если там пусто — возьми из `modes/_custom.md`
  → раздел **«Поисковый профиль»**. В любом случае — реальные слова-навыки, НЕ громкие
  архетипы вроде «AI Engineer». Учитывай приоритет каналов (фриланс + стартапы > corporate Indeed).
- **Свои слова:** возьми то, что назвал пользователь.

> 💡 Для бордов и фриланса лучше **короткие слова-навыки** (`python`, `react`,
> `automation`, `telegram bot`, `no-code`), а не длинные фразы-роли. Так больше
> совпадений. (Фильтр теперь и длинные фразы разбивает на слова, но короткие — точнее.)

## Шаг 3. Запустить ВСЕ подходящие площадки

Все результаты идут в `data/pipeline.md`.

### A. Наём (полная/частичная) + Удалённо

**1) Международные борды — JobSpy** (Indeed, LinkedIn, Glassdoor, Google, ZipRecruiter):
```bash
./.venv/bin/python sources/jobspy_search.py "<q1>" "<q2>" "<q3>" --remote --results 25 [--job-type fulltime|parttime]
```

**2) Компании и нишевые борды — ДВА прохода (важно — оба!):**
```bash
# (a) ATS-API (zero-token): Greenhouse/Ashby/Lever у отслеживаемых компаний
node scan.mjs
```
```bash
# (b) Remote-борды через их БЕСПЛАТНЫЕ фиды (Remotive, RemoteOK, WeWorkRemotely,
#     Working Nomads). Отдают десятки вакансий и НЕ блокируются VPN.
node sources/boards_search.mjs "<q1>" "<q2>" "<q3>"
```
```
# (c) Wellfound — у него нет API, поэтому только через WebSearch:
#     выполни WebSearch 'site:wellfound.com/jobs "<роль>" remote' по ролям пользователя,
#     собери ссылки и добавь строками "- [ ] {url} | {company} | {title} | {location}"
#     в раздел "## Pending" файла data/pipeline.md (без дублей).
```

### B. Наём (полная/частичная) + На месте (город X)
```bash
./.venv/bin/python sources/jobspy_search.py "<q1>" "<q2>" --location "Город, Страна" --country "Страна" --results 25 [--job-type fulltime|parttime]
```
Плюс при желании прогон бордов через WebSearch (шаг 2b) с добавлением города в запрос.

### C. Фриланс (проекты)
```bash
# Реальные фриланс-проекты (Freelancer.com) + контрактные роли (Remotive/RemoteOK)
node sources/freelance_search.mjs "<q1>" "<q2>" "<q3>"
# Дополнительно — контрактные вакансии с Indeed/LinkedIn:
./.venv/bin/python sources/jobspy_search.py "<q1>" "<q2>" --remote --job-type contract --results 25
```
**Честно:** Upwork / Fiverr / Kwork НЕ подключены (нет открытого API) — скрипт об этом сам напишет.

## Шаг 4. Отчитаться и предложить оценку

Скажи, сколько нашлось и из каких источников, например:
> «Нашёл 64 вакансии: 47 JobSpy (Indeed/LinkedIn), 11 бордов (Wellfound, RemoteOK),
>  6 компаний (ATS). Запустить оценку под твой профиль?»

Если согласен — `/career-ops pipeline` (оценка A–F под резюме, отбор подходящих,
отсев не того региона/уровня). НИКОГДА не подавай заявки сам.
