# JobForge 🔨

**Личный AI-помощник для поиска работы и фриланса.** Работает внутри
[Claude Code](https://claude.com/claude-code): ищет вакансии по многим площадкам,
оценивает их под твоё резюме и готовит резюме + сопроводительное под каждую. Откликаешься сам.

## Что умеет

- 🔎 **Ищет везде сразу:** международные борды (Remotive, RemoteOK, We Work Remotely,
  Working Nomads), Indeed/LinkedIn (через JobSpy), стартапы (Wellfound), компании
  (Greenhouse/Ashby/Lever) и фриланс (Freelancer.com).
- ⚖️ **Оценивает фит** каждой вакансии под твоё резюме (балл A–F, гэпы, красные флаги).
- 📄 **Готовит материалы:** уникальное резюме под каждую вакансию + сопроводительное
  письмо (с очисткой от «робо-стиля»). Формы НЕ заполняет — подаёшь сам.

## Что нужно

- [Claude Code](https://claude.com/claude-code) (десктоп-приложение или CLI)
- [Node.js](https://nodejs.org)
- [Python 3.10+](https://www.python.org) — для широкого поиска через JobSpy (опционально)

## Установка (3 шага)

```bash
# 1) Скачай проект (или распакуй ZIP) и зайди в папку
# 2) Поставь всё одной командой:
bash setup.sh
# 3) Открой папку проекта в Claude Code и напиши:
#    настрой JobForge
```

Дальше дружелюбный мастер соберёт твоё резюме и спросит, что ищешь.

## Как пользоваться

1. **Настройка** — «настрой JobForge» (резюме + что ищешь). Один раз.
2. **Поиск** — «найди вакансии». Ищет по всем площадкам.
3. **Оценка** — «оцени» → балл A–F под твоё резюме, отсев лишнего.
4. **Выбор** — смотришь шортлист, отмечаешь, на какие откликаться.
5. **Отклик** — «подготовь отклик» → резюме + письмо под каждую. Подаёшь сам.

💡 Можно и без поиска: **кинь ссылку на вакансию** → «оцени и подготовь отклик».
